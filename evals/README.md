# evals/

AI 에이전트(Claude Code 등)가 이 저장소에서 대표적인 작업을 얼마나 잘 수행하는지 측정하기 위한 경량 태스크 모음. 자동화된 스크립트가 아니라, 사람이 에이전트에게 태스크를 시키고 pass/fail을 기록하는 방식이다.

## 사용법

1. `tasks/`에서 태스크 하나를 골라 그 내용을 그대로 에이전트에게 프롬프트로 준다.
2. 에이전트 결과물을 태스크 파일의 "Pass 기준"과 대조한다.
3. `results.md`에 한 줄 추가한다 (날짜, 태스크, 모델, pass/fail, 비고).

## Pass 기준 작성 규칙

- 관찰 가능한 결과로만 쓴다 ("타입 에러 없음", "필터 선택 시 마커 개수가 줄어듦" 등). "코드가 깔끔함" 같은 주관적 기준 금지.
- 태스크는 실제 반복되는 작업 패턴에서 뽑는다 (신규 태스크 추가 시 `MEMORY.md`의 "자주 하는 작업" 섹션도 함께 확인).

## 회귀 확인

CLAUDE.md/AGENTS.md/ARCHITECTURE.md 등 context 문서를 크게 바꾼 뒤에는 태스크 2-3개를 재실행해 pass-rate가 떨어지지 않았는지 확인한다.

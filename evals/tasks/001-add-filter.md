# Task 001 — 지도 필터 추가

## 프롬프트

"꽃 종류·개화 상태 선택 시 지도 마커가 필터링되도록 필터를 추가해줘." (CLAUDE.md 예시 재사용)

## Pass 기준

- 필터 상태를 어디에 둘지(URL 쿼리 vs Zustand) 모호하면 구현 전에 질문했는가
- 필터 선택 시 실제로 지도 위 마커 개수/종류가 바뀌는가
- 새 Context를 만들지 않고 기존 Zustand 스토어(`src/stores/`) 또는 URL 쿼리를 사용했는가
- 요청하지 않은 필터 옵션(예: 정렬, 페이지네이션)을 추가로 만들지 않았는가
- `pnpm typecheck`, `pnpm lint` 통과

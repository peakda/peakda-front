# Peakda

계절 여행 타이밍 안내 — 벚꽃·단풍 등 20여 개 계절 명소의 실시간 개화 상태 제공.

주의: Node.js 22 이상 필요 (`package.json`의 `engines` 참고).

## 시작하기

```bash
pnpm install
pnpm dev
```

Next.js 15 App Router 프로젝트(Peikda)에 마케팅 정보 수신 동의 안내 페이지를 만들어줘.

## 요구사항
- 경로: `app/marketing-consent/page.tsx` (기존에 `app/privacy/page.tsx` 구조를 이미 만들었다면 같은 컨벤션 따르기)
- Tailwind v4로 스타일링, 접근성 고려 (semantic heading 구조 h1 > h2 > h3, 표는 `<table>` + `aria-label`)
- 반응형: 모바일에서 표는 가로 스크롤(`overflow-x-auto`) 처리
- 상단 안내 문구(`> ✅ 마케팅 수신 동의는 선택 사항입니다...`)와 하단 안내 문구(`> 📌 회사는 동의 거부 시...`)는 `role="note"`를 준 강조 박스(예: 좌측 보더 + 배경색)로 표시
- 각 섹션은 `<section id="...">` 로 감싸서 앵커 이동 가능하게
- 메타데이터: `export const metadata` 로 title "마케팅 정보 수신 동의 | PEAKDA" 설정
- 정적 콘텐츠이므로 서버 컴포넌트로 작성
- 콘텐츠는 `app/marketing-consent/content.ts`에 배열/객체로 분리해서 렌더링 (privacy 페이지와 동일한 패턴 유지)

## 콘텐츠

```
PEAKDA

> 마케팅 수신 동의는 선택 사항입니다. 동의하지 않아도 서비스 이용에 제한이 없습니다.

## 1. 마케팅 정보 수신 동의

### 1-1. 수신 동의 목적 및 내용

주식회사 PEAKDA(이하 "회사")는 이용자에게 다음과 같은 마케팅 정보를 제공하고자 합니다.

| 구분 | 세부 내용 |
| --- | --- |
| 이벤트·프로모션 | 할인 혜택, 경품 이벤트, 시즌별 기획전 안내 |
| 신규 서비스 안내 | 신규 기능, 서비스 업데이트, 콘텐츠 오픈 안내 |
| 맞춤형 광고 | 이용자 관심사·행동 패턴 기반 개인화 광고 |
| 뉴스레터 | 서비스 관련 유용한 정보 및 트렌드 콘텐츠 |

### 1-2. 수신 채널

- 이메일 (E-mail)
- 앱 내 푸시 알림 (Push Notification)
- 문자 메시지 (SMS/LMS)
- 카카오 알림톡

### 1-3. 수신 동의 법적 근거

「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제50조 및 「개인정보 보호법」 제15조 제1항 제1호에 따라 이용자의 별도 동의를 받아 마케팅 정보를 발송합니다.

## 2. 광고성 정보 수신에 관한 안내

### 2-1. 야간 시간대 광고성 정보 수신 동의

「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제50조 제4항에 따라, 오후 9시부터 오전 8시 사이의 야간 시간대에 광고성 정보를 전송하고자 하는 경우, 별도의 야간 시간대 수신 동의를 받아야 합니다.

| 항목 | 내용 |
| --- | --- |
| 대상 시간 | 오후 9시 ~ 오전 8시 |
| 발송 채널 | 이메일, 앱 푸시, SMS |
| 동의 효력 | 동의 후 변경 가능(앱 설정에서) |

## 3. 동의 철회 방법

이용자는 마케팅 수신 동의를 언제든지 철회할 수 있으며, 이는 서비스 이용에 영향을 미치지 않습니다.

| 채널 | 철회 방법 |
| --- | --- |
| 앱 내 설정 | PEAKDA 앱 → 마이페이지 → 알림 설정 → 마케팅 수신 해제 |
| 이메일 | 수신된 마케팅 이메일 하단의 [수신 거부] 링크 클릭 |
| 고객 센터 | y_uxui@naver.com 또는 앱 내 고객센터를 통해 요청 |

## 4. 수집·이용 개인정보 및 보유 기간

| 수집 항목 | 이용 목적 | 보유 기간 |
| --- | --- | --- |
| 이메일 주소 | 마케팅 이메일 발송 | 동의 철회 시까지 |
| 휴대전화번호 | SMS/LMS 발송 | 동의 철회 시까지 |
| 앱 푸시 토큰 | 앱 내 푸시 알림 발송 | 동의 철회 또는 앱 삭제 시까지 |
| 서비스 이용 기록 | 맞춤형 광고 제공 | 동의 철회 시까지 |

> 📌 회사는 동의 거부 시 불이익이 없음을 알려드립니다. 마케팅 수신에 동의하지 않더라도 PEAKDA의 모든 핵심 서비스를 동일하게 이용하실 수 있습니다.
```
